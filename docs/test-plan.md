# 测试用例与验收说明

## 抠图成功率口径（验收用）

- **样本**：建议不少于 50 张真实人像半身照（室内/室外、纯色/复杂背景、侧光/背光各若干）。
- **成功定义**：云函数返回 `ok:true`，结果 PNG 含有效 alpha，肉眼可见人像主体完整且背景透明（无整图白底）。
- **失败**：格式/超限被拒、无前景、超时、鉴权/余额错误等均计失败，不得伪装成功。
- **口径**：成功率 = 成功次数 / 有效发起次数（前端压缩后通过校验并调用云函数的请求）。目标 &gt;90%。

> 本仓库为脚手架实现，需在真实 CloudBase + 腾讯云账号上跑通后统计。

## 一期用例清单

|------|------|------|
| P1 | 有效 JPG/PNG | 抠图成功，`getTempFileURL` 可显示 |
| P2 | 损坏图片 | 不调用或 API 失败，中文提示 |
| P3 | 超限文件 / 超限分辨率 | 前端或云函数拦截，不调用 API |
| P4 | 不支持格式（如 GIF） | 拦截 |

| P6 | 同用户同 hash 重复/并发 | 仅一次第三方 API；其余 cacheHit |

| P8 | 超时/限频/鉴权/余额/无人像 | 对应中文码，不伪装成功；超时类最多重试 1 次 |
| P9 | 透明 PNG alpha | 无白底；mask 合成时边缘按置信度 |
| P10a | `ENABLE_REWARD_AD=false`（默认）点击高清导出 | 不创建/加载/展示广告，直接进入保存；无需广告位 ID |
| P10b | `ENABLE_REWARD_AD=true` 且完整观看 | `onClose` 且 `isEnded===true` 解锁并保存 |
| P11 | `ENABLE_REWARD_AD=true` 时跳过/关闭/未加载/onError/重复点击 | 100% 不解锁；广告失败不得变成免广告下载 |
| P11b | `ENABLE_REWARD_AD=true` 但未配置广告位 | 提示无法解锁，不保存 |
| P12 | 保存相册权限拒绝 | 提示授权；开启广告时不误报为广告未完成 |
| P13 | 自定义尺寸边界 | 单边 50–4000、总像素≤1600万、mm 范围 |
| P14 | 尺寸搜索 | 名称/分类/别名/关键词 |
| P15 | 隐私同意/拒绝 | 拒绝不上传、不调第三方 |
| P16 | UV 并发 | openid+日期唯一 |
| P17 | Canvas 失败 / 临时 URL 失效 | 提示重试；URL 可再取一次 |
| P18 | 密钥扫描 | 前端与构建产物无 SecretId/Key |
| P19 | 渐变参数 | 可见且 70% 起点、15% 过渡 |
| P20 | 排版开关 | 默认关闭 |
| P21 | 激励视频开关 | `ENABLE_REWARD_AD` 默认关闭 |

## 验收补充（广告开关）

- 默认关闭激励视频：高清导出可直接保存，流程中不出现广告组件调用。
- 开关开启后恢复严格广告状态机；仅完整观看解锁。
- 免广告与否**只**看 `ENABLE_REWARD_AD`，广告加载失败不能当作免广告。

## 二期用例

- A4 / 6寸4R × 1寸(4×2=8) / 2寸(2×2=4)
- 单排/双排：1、最大可容纳、10、越界
- 刚好容纳与超出 1px
- 预览坐标 = 导出坐标
- 广告规则（`ENABLE_REWARD_AD=true` 时）与换图/改版式后解锁失效
- `ENABLE_REWARD_AD=false` 时排版高清导出同样直接保存、不播广告

## 三期用例

- 普通用户 / 管理员页面与接口
- 篡改客户端 openid、直接调写接口 → 拒绝
- 管理员缺失或鉴权失败 → 默认拒绝
- 合法/非法尺寸、重复、停用、排序
- 双管理员并发编辑 → VERSION_CONFLICT
- 启动拉取 / 版本不变 / 版本更新 / 云端失败有无缓存
- `configs` 无敏感字段；停用尺寸不可被普通用户搜到
